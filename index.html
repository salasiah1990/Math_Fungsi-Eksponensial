A

Definisi Fungsi Eksponensial

Fungsi eksponensial adalah suatu fungsi yang memetakan setiap bilangan real x ke bilangan real a · bˣ, dengan bentuk umum:

f(x) = a · bˣ

Syarat mutlak: b > 0, b ≠ 1, a ≠ 0, dan x ∈ ℝ

Mengapa b > 0 dan b ≠ 1?

  • Jika b = 1, maka f(x) = a · 1ˣ = a (menjadi fungsi konstan, bukan eksponensial).
  • Jika b ≤ 0, untuk nilai x pecahan (misal x = ½), f(½) = b^(1/2) = √b bisa menghasilkan bilangan imajiner (tidak terdefinisi di ℝ).
B

Kalkulator Eksplorasi Sifat

Ubah nilai basis (b) dan pangkat (x) untuk mengamati bagaimana nilai fungsi berubah secara drastis!

Hasil Perhitungan: Monoton Naik

f(3) = 2³ = 8

Karena b > 1, semakin besar nilai x, nilai f(x) tumbuh semakin cepat.

Sifat-Sifat Utama Grafik Fungsi Eksponensial f(x) = bˣ

1. Domain & Range

Daerah asal (Domain) adalah seluruh bilangan real (-∞, ∞), sedangkan daerah hasil (Range) selalu positif (0, ∞).

2. Titik Potong Sumbu Y

Untuk f(x) = bˣ, grafik selalu memotong sumbu Y di titik (0, 1) karena setiap bilangan b > 0 dipangkatkan 0 bernilai 1.

3. Asimtot Datar

Sumbu X (garis y = 0) adalah asimtot datar. Kurva mendekati sumbu X namun tidak pernah menyentuh atau memotongnya.

4. Kemonotonan

Jika b > 1 grafik monoton naik (pertumbuhan). Jika 0 < b < 1 grafik monoton turun (peluruhan).

Laboratorium Grafik

Amati transformasi fungsi f(x) = a · bˣ + c secara langsung.

f(x) = 1 · (2.0)ˣ + 0

Koefisien Awal (a) 1

Mengatur peregangan vertikal & pencerminan sumbu X.

Basis (b) 2.0

b > 1: Pertumbuhan | 0 < b < 1: Peluruhan (b ≠ 1).

Pergeseran Vertikal / Asimtot (c) 0

Menggeser grafik naik/turun dan menentukan asimtot datar y = c.

Analisis Karakteristik Saat Ini:

• Titik Potong Sumbu Y: (0, 1)

• Asimtot Datar: y = 0

• Sifat Kemonotonan: Monoton Naik
